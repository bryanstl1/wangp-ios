Operativo

Inspecciona un checkpoint o ejecuta el bloque 0 de Wan 2.1 T2V 1.3B. Se leen solo los fragmentos necesarios; no se descarga el modelo entero.

Safari puede borrar la caché. Solo se activa para la revisión oficial fijada. No es una descarga completa para uso sin conexión.

Ningún checkpoint inspeccionado.

La prueba del bloque lee unos 186 MB de pesos oficiales y usa 2 tokens con entradas artificiales conocidas. Compara la salida con PyTorch. Es una capa real del modelo; no genera video.
